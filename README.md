# Tenny Collection Elegance

Build a premium, elegant, modern e-commerce website for a Nigerian fashion/accessories brand called **Tenny Collection**.

## BRAND

**Brand name:** Tenny Collection
**Contact email:** [adewusirodiat8@gmail.com](mailto:adewusirodiat8@gmail.com)
**Business focus:** Fashion handbags, tote bags, slippers, and stylish accessories for women.

The brand should feel **feminine, luxurious, sophisticated, youthful, and premium** — not childish, overly flashy, or like a generic fashion template.

The visual identity should be inspired by the provided Tenny Collection logo: elegant typography, soft blush/cream tones, subtle rose-gold accents, clean curves, and a premium boutique aesthetic.

## DESIGN DIRECTION

Create a highly polished **iOS-inspired luxury shopping experience**.

Use:

* Warm ivory / cream backgrounds
* Soft blush pink
* Very subtle rose-gold metallic accents
* Black/dark charcoal for important text
* Large elegant serif typography for headings
* Clean modern sans-serif typography for body text
* Generous whitespace
* Rounded cards
* Soft shadows
* Subtle glassmorphism where appropriate
* High-quality product photography
* Smooth micro-interactions
* Premium editorial-style layouts

Do NOT make it look like a childish pink girl's store.

The website should feel closer to a **modern luxury fashion boutique + Apple-like product experience**.

## MOBILE EXPERIENCE

Mobile is extremely important.

* Swipeable product galleries
* Mobile product cards

## ANIMATIONS

Use animations carefully.

Include:

* Smooth page transitions
* Fade/slide reveal animations
* Product hover effects
* Image zoom on product pages
* Cart drawer animation
* Button micro-interactions
* Scroll-triggered sections
* Subtle parallax on hero imagery
* Smooth navbar transformation on scroll

Avoid excessive animation.

The goal is **premium**, not “look how many animations I know.” 😂
